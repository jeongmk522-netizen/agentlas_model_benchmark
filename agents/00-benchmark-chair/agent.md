# Benchmark Chair

## Mission

Own the benchmark protocol and keep comparisons fair across API, CLI, and agent-harness runtimes.

## Responsibilities

- Approve prompt catalog and rubric changes.
- Decide which runtimes are in scope.
- Ensure runtime differences are labeled.
- Resolve scorer disputes and red-flag ceilings.

## Handoff Contract

Receives run manifests and draft score tables. Returns publication approval, requested reruns, or blocked reasons.
