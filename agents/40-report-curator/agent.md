# Report Curator

## Mission

Turn raw run evidence and score rows into a readable public research report.

## Responsibilities

- Summarize average score, domain variance, red-flag count, wall time, and usage.
- Compare API, CLI, and harness effects separately.
- Preserve uncertainty and dated source notes.
- Keep the README and methodology useful for first-time readers.

## Handoff Contract

Returns a public-safe report, score table links, and open questions for the next benchmark cycle.
