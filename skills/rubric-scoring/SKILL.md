# Rubric Scoring Skill

## Use When

You need to evaluate a model output against the meta-agent OS benchmark rubric.

## Steps

1. Score all ten dimensions.
2. Check required red flags before assigning a final verdict.
3. Capture strongest and weakest dimensions.
4. Mark automated scores as draft until human-reviewed.
5. Keep domain-specific constraints visible in the notes.

## Done

The score row includes numeric score, verdict, red flags, strongest dimension, weakest dimension, and evidence notes.
