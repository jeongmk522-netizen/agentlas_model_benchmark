# Public Safety Skill

## Use When

You are preparing benchmark artifacts for a public repository.

## Steps

1. Search for provider keys and private local paths.
2. Remove raw private logs or unpublished transcripts.
3. Keep raw model outputs outside the repo unless reviewed.
4. Run `scripts/public_safety_check.sh`.
5. Document any remaining uncertainty in the report.

## Done

The repo is safe to publish and the safety check passes.
